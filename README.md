# Bike Racing

A small neon-sunset bike racing game packaged as an Android app with a local WebView. The game runs offline and uses no external assets or runtime services.

## Open and run on Android

1. Open this repository in Android Studio (Android Studio Koala or newer; Android SDK 35 installed).
2. Let Gradle sync, then run the `app` configuration on an emulator or Android device.

The app launches in landscape, immersive full-screen mode. You can also preview the game by opening `app/src/main/assets/index.html` in a desktop browser.

## Controls

- **Left / Right:** steer with the on-screen arrows or swipe.
- **GO:** accelerate (held).
- **BRAKE:** slow down (held).
- **NITRO:** hold for a temporary speed boost; the gauge recharges when unused.
- **Pause:** tap the top-right button.

Dodge traffic, collect glowing energy pickups, cover distance, and beat your saved best score.
